مركز تحديثات الموقع

إدارة تحديثات التصميم والمحتوى وملفات البرمجة من مكان واحد
خاص بالإدارة

الصق هنا حزمة JSON التي تم تجهيزها للموقع، افحصها أولًا، ثم اعتمدها لحفظ التغييرات. يدعم المركز الألوان والنصوص المخصصة وبعض روابط الصور وإعدادات المظهر الحالية فقط. لا يشغّل أكواد برمجية أو HTML أو أوامر نظام. إضافة صفحات أو قوائم أو وظائف جديدة تحتاج تعديلًا برمجيًا ومراجعة ونشر إصدار جديد.

لم يتم فحص أي حزمة بعد.

هذا المركز يقبل حزمة واحدة تحتوي تغييرات متعددة في ملفات المشروع: إضافة ملفات جديدة، استبدال محتويات ملفات موجودة، أو حذف ملفات غير محمية. يدعم ملفات الواجهة وواجهات API ومكتبات الخادم والاختبارات والإعدادات وترحيلات SQL النصية. عند الاعتماد، تُسجّل التغييرات مباشرة على فرع main وتبدأ عملية نشر Production المعتادة؛ لا ينشئ رابط Preview منفصلًا.

الحزمة لا تنفّذ أوامر من المتصفح ولا تستخدم eval. ملفات الأسرار ومفاتيح الاعتماد وسير عمل GitHub محمية. ترحيلات SQL تُحفظ داخل المشروع فقط ولا تُنفّذ تلقائيًا على قاعدة البيانات، وتغيير متغيرات البيئة والأسرار يظل من إعدادات Vercel المحمية.
